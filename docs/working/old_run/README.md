# The earlier validation (run of 4 November 2026)

These documents hold the results of the validation as it was before the
redesign: eleven studies (00–11), run on 4 November 2026 (commit 21d42dc), in
which 137 of 138 checks passed. The scripts they describe, and the report of
that run (`validation/report.html`), remain on the `main` branch.

| File | What it is |
|---|---|
| [`findings.md`](findings.md) | What that run showed, on one page |
| [`comparison.md`](comparison.md) | The three priors compared criterion by criterion, and the recommendation (flat partial r) with its costs |
| [`validation_report.md`](validation_report.md) | Every study and check of that run, with its numbers |
| [`status_of_claims.md`](status_of_claims.md) | The status of each claim after that run |

They are kept as the starting point for `docs/3_results.md`, which will be
written from the redesigned validation ([`validation.ipynb`](../../../validation.ipynb));
the old studies map onto the new ones as described in
[appendix C](../../appendix/C_study_design.md). The figures they show are the
old studies' figures, in [`results/figures/`](../../../results/figures/).
